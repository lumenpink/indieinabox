Indie in a Box

محرك PHP متكامل ومستقل في ملف واحد بدون أي تبعيات خارجية، يشغل موقعك الشخصي، قارئ الخلاصات الاجتماعية، منصة النشر وهويتك اللامركزية عبر شبكات IndieWeb وFediverse وTwtxt وGemini وGopher.

⬇ ⬇ تحميل الإصدار v1.0.0 (2 ميغابايت) استكشف أوامر سطر الأوامر CLI ← دليل بروتوكول Twtxt وYarns
بدون تبعيات خارجية

بدون أوامر تثبيت معقدة. فقط ضع الملف في الخادم.

تم تجميع Indie in a Box بالكامل في ملف تنفيذي واحد בלבד: indieinabox.php. لا تحتاج إلى سكريبتات تحميل مبهمة، ولا إلى Composer في خادم التشغيل، ولا إلى Node.js أو خوادم قواعد بيانات ثقيلة.

كل ما عليك فعله هو وضع indieinabox.php في مجلد الخادم أو داخل حاوية Docker. يقوم المحرك تلقائياً بإنشاء قاعدة بيانات SQLite سريعة بنمط WAL والعمل فوراً.

BASH / الطرفية (تشغيل سريع في 10 ثوانٍ) 
# 1. Download the standalone executable
curl -LO https://codeberg.org/indieinabox/indieinabox/releases/download/v1.0.0/indieinabox.php

# 2. Run the interactive setup (or pass --setup flags)
php indieinabox.php setup

# 3. Start the built-in development web server
php indieinabox.php --serve
# Listening on http://localhost:8080 - Open in browser to access Admin Dashboard!
جماليات المواجهة // رفض الغسيل الوردي للشركات (ANTI-PINKWASHING)

احتلال الفضاء الرقمي وخندق المقاومة DIY

على أرصفة أمريكا اللاتينية والجنوب العالمي، ملصقات الشوارع (Lambe-Lambe) هي وسيلة الإعلام الجماهيرية لمن لا يملك أموالاً للوحات الإعلانية الضخمة أو خوارزميات المراقبة لشركات التقنية الكبرى. إنها الملصقات التي تُلصق في الثالثة فجراً بعجينة دقيق وماء منزلية لتنافس رمادية الإسمنت وإعلانات الاستهلاك.

إن إحضار هذه الهوية المتمردة إلى Indie in a Box هو إعلان واضح بأن البرمجيات الحرة هي سلاح في خندق المواجهة—معادية للتجميل الشركاتي النيوليبرالي (Pinkwashing) في وادي السيليكون، ومبنية على الاعتراف الصريح بحق المقاومة الكويرية والشعبية المستقلة.

01 // ركائز البنية الأساسية

⚡

محرك تشغيل PHP في ملف أحادي

نظام التشغيل بالكامل بما فيه التوجيه، محرك القوالب، معالج Markdown، microformats2، قاعدة SQLite، والتوقيع الرقمي مدمج في ملف indieinabox.php.

🌐

إتقان ثلاثي البروتوكولات

دعم أصيل وشامل لـ IndieWeb (Micropub, Microsub, Webmention) و Fediverse (ActivityPub C2S/S2S, Group Actors) و Twtxt & Yarns.

🪐

نشر متزامن على ثلاث شبكات

نشر أي مقال يولد في نفس اللحظة صفحات HTML5 دلالية حديثة، وكبسولات Gemini أصيلة (.gmi)، وخرائط Gopher التراثية (gophermap).

🤖

ترجمة متعددة النماذج بالذكاء الاصطناعي

مسار ترجمة آلي متكامل يدعم نماذج Google Gemini و OpenAI GPT-4o و Anthropic Claude 3.5 و xAI Grok ونماذج Ollama المحلية المستضافة ذاتياً.

🛡️

أدوات الإشراف الفيديرالي والقطع

تحكم دقيق يسمح بإيقاف (SUSPEND) أو إسكات (SILENCE) أي نطاق أو مستخدم، مع تصفية تلقائية للرسائل المزعجة وفق RFC 9457.

📦

حرية تامة في نقل البيانات بدون قيود

جميع بياناتك محفوظة محلياً في ملفات SQLite و Markdown. قم بإنشاء نسخ احتياطية مشفرة بضغطة زر واحدة (.tar.gz أو .zip).

02 // وصفات النشر في بيئة الإنتاج

DOCKER-COMPOSE.YML 
services:
  indieinabox:
    image: dunglas/frankenphp:latest-php8.3
    restart: unless-stopped
    ports:
      - "8080:80"
    environment:
      - SERVER_NAME=https://yourdomain.com
    volumes:
      - ./data:/app/data
      - ./indieinabox.php:/app/public/index.php

قم بربط مجلد البيانات الخاص بك بالمسار /app/data وملف التشغيل بالمسار /app/public/index.php. هذا كل ما تحتاجه!

CLI COMMAND (STANDALONE FRANKENPHP) 
# Run FrankenPHP directly in worker mode
frankenphp run --root /var/www/myblog/public_html
CADDYFILE 
yourdomain.com {
    root * /var/www/myblog
    php_fastcgi 127.0.0.1:9000
    file_server

    # Fallback all dynamic requests to single-file app
    try_files {path} {path}/ /indieinabox.php?{query}
}
NGINX.CONF 
server {
    server_name yourdomain.com;
    root /var/www/myblog;
    index indieinabox.php index.html;

    location / {
        try_files $uri $uri/ /indieinabox.php?$args;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
