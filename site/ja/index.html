Indie in a Box

IndieWeb、Fediverse、Twtxt、Gemini、Gopher ネットワークを横断して個人サイト、ソーシャルリーダー、パブリッシャー、分散型アイデンティティを駆動するゼロ依存の単一ファイルPHPエンジン。

⬇ ⬇ v1.0.0 をダウンロード (2MB) CLI コマンドリファレンス → Twtxt & Yarns ガイド
外部依存ゼロ

面倒なインストール手順なし。ファイルを置くだけ。

Indie in a Box は単一の実行可能 PHP ファイル indieinabox.php にすべてコンパイルされています。複雑なインストーラスクリプト、Composer、Node.js、外部DBデーモンは一切不要です。

サーバーや Docker ボリュームに indieinabox.php を配置するだけ。自動的に WAL モードの SQLite データベースが構築され、即座に起動します。

BASH / ターミナル（10秒クイックスタート） 
# 1. Download the standalone executable
curl -LO https://codeberg.org/indieinabox/indieinabox/releases/download/v1.0.0/indieinabox.php

# 2. Run the interactive setup (or pass --setup flags)
php indieinabox.php setup

# 3. Start the built-in development web server
php indieinabox.php --serve
# Listening on http://localhost:8080 - Open in browser to access Admin Dashboard!
対決の美学 // 反ピンクウォッシング（ANTI-PINKWASHING）

デジタルの占領と DIY の塹壕

ラテンアメリカのアスファルトにおいて、小麦粉と水の糊で貼るストリートポスター（Lambe-Lambe）は、巨大広告やアルゴリズムを買う資本を持たない庶民のための唯一のマスメディアです。午前3時にコンクリート壁に張り巡らされ、都市の灰色の風景と戦い続けます。

この剥き出しのアイデンティティを Indie in a Box に持ち込むことは、フリーソフトウェアが前線の武器であることを視覚的に宣言することです——シリコンバレーの無菌化されたピンクウォッシングを拒絶し、トランスジェンダーや草の根の自治の力を称えます。

01 // 中核となるアーキテクチャ

⚡

単一ファイル PHP ランタイム

ルーティング、テンプレート描画、Markdownパーサー、microformats2、SQLite ORM、暗号署名を含む全機能が indieinabox.php 1ファイルに内包されています。

🌐

トリプルプロトコルの融合

IndieWeb（Micropub、Microsub、Webmention）、Fediverse（ActivityPub C2S/S2S、グループActor FEP-1b12）、Twtxt & Yarns をネイティブ統合。

🪐

3大ネットワークへの同時配信

投稿すると、最新のセマンティックHTML5に加え、Geminiプロトコル（.gmi）とGopherマップ（gophermap）が自動で同時生成されます。

🤖

マルチプロバイダー AI 自動翻訳

Google Gemini、OpenAI GPT-4o、Anthropic Claude 3.5、xAI Grok、ローカル Ollama モデルに対応した自動多言語翻訳パイプラインを内蔵。

🛡️

連合モデレーション＆遮断スイート

ドメイン単位や個別Actor単位での SUSPEND や SILENCE、RFC 9457 に準拠した自動スパム遮断機能を備えています。

📦

ベンダーロックイン完全排除

全データはローカルの SQLite と Markdown に保存されます。CLI または管理画面から1クリックで暗号化バックアップ（.tar.gz / .zip）が可能です。

02 // 本番環境デプロイ例

DOCKER-COMPOSE.YML 
services:
  indieinabox:
    image: dunglas/frankenphp:latest-php8.3
    restart: unless-stopped
    ports:
      - "8080:80"
    environment:
      - SERVER_NAME=https://yourdomain.com
    volumes:
      - ./data:/app/data
      - ./indieinabox.php:/app/public/index.php

データ保存先を /app/data に、単一ファイルを /app/public/index.php にマウントするだけ。これだけで完結します！

CLI COMMAND (STANDALONE FRANKENPHP) 
# Run FrankenPHP directly in worker mode
frankenphp run --root /var/www/myblog/public_html
CADDYFILE 
yourdomain.com {
    root * /var/www/myblog
    php_fastcgi 127.0.0.1:9000
    file_server

    # Fallback all dynamic requests to single-file app
    try_files {path} {path}/ /indieinabox.php?{query}
}
NGINX.CONF 
server {
    server_name yourdomain.com;
    root /var/www/myblog;
    index indieinabox.php index.html;

    location / {
        try_files $uri $uri/ /indieinabox.php?$args;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
