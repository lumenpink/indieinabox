Indie in a Box

零外部依赖的单文件 PHP 个人网站引擎，跨越 IndieWeb、Fediverse 联邦宇宙、Twtxt、Gemini 与 Gopher 网络，驱动个人阅读器、发布器与数字主权身份。

⬇ ⬇ 下载 v1.0.0 (2MB) 查阅 CLI 命令行参考 → Twtxt 与 Yarns 使用指南
零额外依赖

无需复杂安装脚本。直接拖入文件即可运行。

Indie in a Box 完全打包编译为一个单一的 PHP 可执行文件：indieinabox.php。你不需要复杂的 curl 管道脚本、Composer 编译链、Node 工具流，也不需要笨重的 SQL 守护进程。

只需将 indieinabox.php 放入服务器目录、Docker 卷或静态虚拟主机中，它会自动生成自带 WAL 模式的高性能 SQLite 数据库并即刻启动。

BASH / 终端（10 秒极速启动） 
# 1. Download the standalone executable
curl -LO https://codeberg.org/indieinabox/indieinabox/releases/download/v1.0.0/indieinabox.php

# 2. Run the interactive setup (or pass --setup flags)
php indieinabox.php setup

# 3. Start the built-in development web server
php indieinabox.php --serve
# Listening on http://localhost:8080 - Open in browser to access Admin Dashboard!

01 // 核心架构支柱

⚡

单文件 PHP 原生运行时

完整运行时系统（包含路由、模板引擎、Markdown 解析器、microformats2、SQLite ORM 和加密签名）全部内嵌于单个 indieinabox.php 文件中。

🌐

三重协议原生贯通

原生支持 IndieWeb（Micropub、Microsub、Webmention）、Fediverse（ActivityPub C2S/S2S、群组 Actors FEP-1b12）和 Twtxt & Yarns 纯文本微博客。

🪐

三网同步多维分发

发布任意文章时，将同时生成现代语义化 HTML5 网页、原生 Gemini 协议胶囊（.gmi）和经典 Gopher 协议导航图（gophermap）。

🤖

多提供商 AI 自动多语言翻译

内置自动化多语言翻译流水线，无缝支持 Google Gemini、OpenAI GPT-4o、Anthropic Claude 3.5、xAI Grok 及本地私有部署 Ollama 模型。

🛡️

联邦治理与去联邦化套件

提供基于域名或 Actor 维度的 SUSPEND 和 SILENCE 细粒度拦截阻断，内置符合 RFC 9457 的自动化防垃圾协议。

📦

零厂商锁定与完全可携性

所有数据均储存在本地 SQLite 与 Markdown 文件中。一键即可导出包含密码学校验哈希的 .tar.gz 或 .zip 完整备份包。

02 // 生产环境部署方案

DOCKER-COMPOSE.YML 
services:
  indieinabox:
    image: dunglas/frankenphp:latest-php8.3
    restart: unless-stopped
    ports:
      - "8080:80"
    environment:
      - SERVER_NAME=https://yourdomain.com
    volumes:
      - ./data:/app/data
      - ./indieinabox.php:/app/public/index.php

将持久化数据目录挂载到 /app/data，单文件应用挂载至 /app/public/index.php。仅此而已！

CLI COMMAND (STANDALONE FRANKENPHP) 
# Run FrankenPHP directly in worker mode
frankenphp run --root /var/www/myblog/public_html
CADDYFILE 
yourdomain.com {
    root * /var/www/myblog
    php_fastcgi 127.0.0.1:9000
    file_server

    # Fallback all dynamic requests to single-file app
    try_files {path} {path}/ /indieinabox.php?{query}
}
NGINX.CONF 
server {
    server_name yourdomain.com;
    root /var/www/myblog;
    index indieinabox.php index.html;

    location / {
        try_files $uri $uri/ /indieinabox.php?$args;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
